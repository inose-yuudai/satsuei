# 3D キャラ用の撮影

スマホで自分を撮って、3D キャラクターの材料になる写真・動画を 1 つの ZIP にまとめるページです。
画面と声の案内どおりに動くと、顔の向き・表情・手の形・全身のポーズが合ったところで自動で撮ります。

- 公開先: GitHub Pages（このリポジトリの `main` の中身がそのまま出る）
- 撮るもの: 顔と髪 11・表情 17・手 8・全身 7（全部で約 11 分。動画 4 本を含む）
- できる物: `撮影_<名前>_<日時>.zip`（写真・動画・点の位置のデータ・`00_はじめに読む.txt`・`00_manifest.json`・一覧の画像）

## 写真のあつかい
- 撮った物は、撮る人の端末のブラウザの中（IndexedDB）にだけ置く。サーバーには送らない
- `index.html` の Content-Security-Policy で、つなぐ先をこのサイトだけに絞ってある（外に送る道がない）
- 顔や手を見分ける MediaPipe も `vendor/` に置き、外のサーバー（CDN・Google）には読みに行かない
- 最後に ZIP を端末に保存（または共有）して、撮った人が自分で送る。「この端末から消す」で消せる

## 配り方
URL をそのまま渡す。LINE で送る時は、末尾に `?openExternalBrowser=1` を付けると、LINE の中ではなく、いつものブラウザで開く（LINE の中ではカメラや保存がうまく動かないことがある）。

## ファイル
| ファイル | 中身 |
|---|---|
| `index.html` / `style.css` | 画面（スマホの縦が基本。横長の画面では右に案内） |
| `app.js` | 進行・判定・撮影・端末の中への保存・ZIP |
| `steps.js` | 撮る手順（角度・表情・手・全身の判定と案内の文） |
| `pictos.js` | お手本の絵 |
| `zip.js` | 小さな ZIP 作り（圧縮しない格納方式。UTF-8 の名前） |
| `vendor/mediapipe/` | MediaPipe Tasks Vision 0.10.14 と判定のモデル（Apache License 2.0。`README.txt`） |

## 手元で確かめる
`python3 -m http.server 8791` などで配り、`http://127.0.0.1:8791/?test&fake=<動画>&name=テスト` を開く。
`test`（待ち時間を短く・声なし）と `fake`（カメラの代わりに同じサイトの動画を縦に切って流す）は、localhost の時だけ効く。
`start=<手順の id>`・`phases=face,expr`・`freeze`（合っても撮らずに止める）も使える。

元になったのは、作者を撮るために作った「撮影スタジオ」（Mac の中のサーバーに保存する版）。
